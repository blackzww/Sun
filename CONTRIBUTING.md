# Contribuindo com a Sun ☀️

Obrigado pelo interesse em melhorar a Sun.

A Sun é um projeto open source criado para simplificar Luau. O código pode ser estudado, modificado e melhorado livremente seguindo a licença do projeto.

## Como contribuir

1. Faça um **Fork** do repositório.
2. Crie uma branch para sua alteração.
3. Faça suas modificações.
4. Teste para garantir que funcionalidades existentes continuam funcionando.
5. Abra um **Pull Request** explicando sua mudança.

## Mudanças na linguagem

Ao adicionar uma nova sintaxe, tente manter a principal ideia da Sun:

> Tudo que puder ser simplificado sem criar confusão deve ser simplificado.

Evite criar uma sintaxe nova quando Luau já possui uma solução simples e legível.

## Código

Tente manter o `sun.lua`:

- simples;
- legível;
- comentado quando necessário;
- sem código ofuscado;
- compatível com funcionalidades existentes.

## Bugs

Encontrou um problema?

Abra uma **Issue → Bug Report** e inclua um código pequeno que reproduza o erro.

## Novas ideias

Para sugerir uma funcionalidade, abra uma **Issue → Feature Request**.

Se possível, mostre como você imagina a sintaxe:

```sun
// exemplo da ideia
```

## Uso de IA

A Sun foi desenvolvida com auxílio de inteligência artificial.

Contribuições feitas com IA também são permitidas, mas o código deve ser revisado e testado antes de ser enviado.
